# Atividades interativas do IMDAZ

Projeto educativo para crianças de 10 anos, composto por duas experiências interativas realizadas em duplas.

A Missão IA reúne perguntas visuais, memória, classificação, localização de intrusos, repetição de comandos e cinco mapas de labirinto. Sua duração estimada é de 70 a 90 minutos.

O Laboratório de Circuitos apresenta uma oficina de 120 minutos inspirada no fluxo de prototipagem do Tinkercad. As equipes reconhecem componentes, montam conexões em uma bancada virtual, organizam programas em blocos, simulam um semáforo e desenvolvem uma travessia segura para pedestres.
