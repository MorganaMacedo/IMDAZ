# Missão IA do IMDAZ

Atividade educativa sobre inteligência artificial para crianças de 10 anos, organizada em treze missões interativas.

O jogo reúne perguntas visuais, memória, classificação, localização de intrusos, repetição de comandos e cinco mapas de labirinto. A aplicação foi planejada para duplas e possui duração estimada de 70 a 90 minutos.

Página pública: https://missao-ia-imdaz.morgana-azevedo.chatgpt.site

## Execução local

```bash
npm install
npm run dev
```
